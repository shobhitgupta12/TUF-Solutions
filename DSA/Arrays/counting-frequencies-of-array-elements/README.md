## 📝 Problem Statement

Given an array **nums** of size **n** which may contain duplicate elements.

Return a list of pairs where each pair contains a unique element from the array and its frequency in the array.

You may return the result in any order, but each element must appear exactly once in the output.

### Example 1

<p>

**Input:** nums = [1, 2, 2, 1, 3]</p><p>

**Output:** [[1, 2], [2, 2], [3, 1]]</p><p>

**Explanation:** </p>- 1 appears 2 times

- 2 appears 2 times

- 3 appears 1 time

Order of output can vary.

### Example 2

<p>

**Input:** nums = [5, 5, 5, 5]</p><p>

**Output:** [[5, 4]]</p><p>

**Explanation:** </p>- 5 appears 4 times.

### Constraints

- 1 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
